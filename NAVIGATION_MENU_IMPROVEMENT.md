# Visible Navigation Menu

Implemented by Yang Yu to make the toolkit navigation easier to discover.

## What changed

- Changed the initial sidebar behavior from always collapsed to responsive `auto` behavior.
- Desktop visitors can see the navigation menu immediately when screen space allows.
- Replaced the subtle collapsed arrow treatment with a high-contrast green `Menu` control.
- Increased the control's touch area, contrast, border, and focus visibility.
- Added a compact mobile treatment so the control remains clear without taking excessive space.

## Verification

- Confirm the menu is visible on first desktop entry after the opening film.
- Confirm a collapsed sidebar presents a labelled `Menu` control rather than an isolated arrow.
- Confirm the control reopens the language and suite navigation.
